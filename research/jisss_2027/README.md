# JISSS 2027 Research Workspace

This directory contains the publication-validation materials for the
planned Journal of International Security & Strategic Studies manuscript.

## Study stages

1. Freeze model provenance
2. Build observed 2026 evidence register
3. Run frozen-specification validation
4. Lock baseline validation results
5. Conduct retrospective calibration separately
6. Conduct sensitivity analysis
7. Develop prospective strategic-warning specification
8. Produce manuscript tables and figures

The research workspace must remain analytically separate from routine
model-development changes.
